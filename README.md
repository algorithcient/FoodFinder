# FoodFinder

## Descripción

FoodFinder es una plataforma web desarrollada por la startup **Sirvo** que conecta emprendedores gastronómicos con consumidores. La aplicación facilita la gestión de pedidos, inventario y ventas para los negocios, mientras que los usuarios pueden encontrar restaurantes, comparar opciones y realizar pedidos de forma rápida y sencilla.

## Enlaces

* 🌐 Aplicación Web: https://sirvo-foodfinder.netlify.app 

## Características

### Consumidores

* Búsqueda de restaurantes.
* Visualización de platos disponibles.
* Consulta de reseñas y calificaciones.
* Seguimiento de pedidos.
* Historial de compras.

### Emprendedores

* Gestión de inventario.
* Gestión de pedidos.
* Administración de platos y precios.
* Creación de promociones.
* Visualización de estadísticas y ventas.
